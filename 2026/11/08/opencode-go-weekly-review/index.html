OpenCode Go 订阅一周用量复盘：月费 ¥68 能跑出多少 token

发表于2026-11-08|更新于2026-11-08|综合实践

先说结论。OpenCode Go 是每月 ¥68（订阅价 $10，全文按 1 USD = 6.8 元人民币一次性换算，此后不再折回）的开源模型订阅：付一份月费，拿到一组已内置计价的开源模型，用量按各模型官方牌价折成等价金额，计入三层使用窗口。本计费周期（10-30 起）在 11-08 上午的配额读数：7 天窗已用 36%、月窗已用 24%；把已消耗部分折回官方等价约 ¥112，照这个节奏走完整月约 ¥544——相当于用 ¥68 扛住约 8 倍杠杆。折扣不在单价里：DeepSeek Flash 在 Go 里的牌价与官方 API 完全一致，省的全部来自「¥68 包 ¥680 月额度」的结构。

订阅机制

三档：Go ¥68/月、Go Plus ¥272/月、Go Teams ¥136/每人，模型清单覆盖 30 款开源模型（DeepSeek、GLM、Kimi、MiniMax、Qwen、MiMo 等）。计价单位不是 token 而是等价金额：每个模型有一张自己的价表，每条请求按所在时段的牌价折算后计入窗口（见 官方定价页）。

额度深度按模型分级，这是整个套餐最要紧的一张表：

模型 月额度
DeepSeek V4.1 Flash ¥680
GLM-5.3-Flash ¥408
GLM-5.3、Kimi 系、Step 5 等 ¥102–204

三层使用窗口是这张表的刻度：5 小时窗取月额度的 20%、7 天窗 50%、月窗 100%。所以对 DeepSeek Flash 来说，5 小时窗 ¥136、周窗 ¥340、月窗 ¥680；最先到线的是周窗——深度只有月窗一半，周中批量高峰会先在这里报警。月窗触顶时官方口径是仍可继续用免费模型，也可打开 Extra Usage 让结算回退到按量计费余额。

本周期窗口读数

配额读数来自网关侧的周期快照，11-08 上午 10:56（北京时间）读到：

窗口 读数
5 小时（滚动） 剩 100%（本窗未起扣）
7 天窗（11-02 00:00 → 11-09 00:00 UTC） 已用 36%
月窗（10-30 14:02 → 11-29 14:02 UTC） 已用 24%

半小时后键内末次读点已推进到 7 天窗 39%、月窗 26%，扣减随用量实时走；单人单机的持续使用整周没有把 5 小时短窗打满。以月窗 24% 对应约 9 天线性外推，全月约 ¥544 官方等价（本文推算，只按「照此节奏」的假设读，牌价固定在 11-08 快照）。

按官方 API 直连用的倍率

官方 DeepSeek API 的牌价与 Go 计价逐项相同（峰谷定义同源：UTC 01:00–04:00 与 06:00–10:00，周一至五），所以「同样流量打官方 API 要花多少」和「配额烧掉多少」是同一笔账。直连的倍率不用逐请求记账，直接用两端读数的比例就能估：每个窗口在自己的周期起点都是 0%，配额快照只留「当前用了百分之几」，把两个端点乘上窗口满度就是绝对金额——下表的「使用比例」列就是这对端点，比例乘满度再摊到 30.44 天，就是官方 API 直连的月账。

情形 直连月账（外推） 相对订阅月费 ¥68
本周期实际流量（等价账实测，到切断点） ≈¥112/周 1.6 倍
使用比例直推·月窗口径（0% → 26%，均摊 30.4 天） ≈¥563 8.3 倍
使用比例直推·7 天窗口径（0% → 39%，斜率月化） ≈¥656 9.7 倍
把 DeepSeek Flash 月额度用满 ¥680 10 倍

也就是说：订阅的回报区间是 1–10 倍官方 API 账单。比例法给出的 8.3–9.7 倍不是营销数字而是两端读数的机械直推——两条斜率的差（8.3 vs 9.7）来自 11-03/04 两个重负载日把周窗斜率抬高，月窗口径被周期前段的低谷摊薄；上限 10 倍要兑现，得把 ¥680 的月额度真正烧完。

  • GLM 是个结构提醒：直连单价只差 3%（¥29.2 对 ¥28.45），比例口径下它整月的官方账 ≈¥93、相对月费 1.4 倍——纯 GLM 用量订阅放大作用有限，直连更划算；智谱自己也把 token 订阅搬上天猫店（个人版 ¥118/月起），两条路都在收拢个人用户，Go 的价值在跨模型打包。
  • 峰谷还有免费优化空间：若 DeepSeek 流量全部落在谷时段，其段账从 ¥82.2 降到约 ¥60.9，省约 26%；按全家通等价账 ¥112 计约省 19%（本周有 36% 的请求发生在工作日高峰时段）。

对照下来，OpenCode Go 的性价比结构其实一句话：主力 DeepSeek Flash + 前缀缓存稳定的 agent 工作流最占便宜——单价与直连持平、折扣来自额度结构、同一份月费里换模型几乎零成本；把高单价的旗舰（GLM-5.3/Kimi 系只有 ¥102 档月额度）当主力反而把折扣摊薄。

局限与口径

三点说在前面：样本是一台机器一个人的 7 天配额窗口，结论只对本机这类 agent 负载成立，不做外推；月度外推依赖「负载节奏不变」的线性假设；官方牌价取自 2026-11-08 的页面快照，页面如有更新以官方页为准。数据全部出自本机网关账本的脚本复算；全部金额按文首汇率一次换算（1 USD = 6.8 CNY），个位有舍入。
